# VitaCheck Unique Responsive HTML Template

Static multipage diagnostic lab template. Open `index.html` directly or deploy the repository root to GitHub Pages.

## Features
- Responsive desktop/tablet/mobile layouts
- Three-color design system
- Dark/light mode with localStorage
- RTL/LTR toggle
- Patient and admin dashboards
- Test/package pages, home collection, report tracking, certification, blog, contact and utility pages
- Local editable JPG placeholders
- Demo downloadable PDF report

## Customize
Change the three design colors in `assets/css/style.css` under `:root`. Replace JPG files in `assets/images/` using the same names.

## Disclaimer
All medical content, pricing and certifications are demonstration placeholders only.
